Top 5 approaches — ranked by leverage × risk

APPROACH 1 · QUICK WIN
Deterministic First, LLM Last — OTel + Drain3 + Regex Cascade
60–80% calls

Litmus/Chaos Mesh already emit OTel attributes that are the lifecycle labels (chaosUID, phase, timestamps). Lift them with a deterministic preprocessor; collapse repetitive spans with Drain3 templates; LLM is invoked only on the residue. AWS CloudWatch Logs Anomaly Detection and Inspect AI both ship this pattern.

Effort: 2–3 days Risk: Very low Phase 0 + Phase 1
Drain3 / LILAC LogParser-LLM OTel CNCF MonitorAssistant FSE'24 AWS CloudWatch
See detailed mapping
APPROACH 2
Cascade Router — Cheap-First, Frontier-on-Disagreement
50–70% $

Wrap AzureLLMClient in a routing layer. Haiku/Phi-3-mini handles the common case; flagship only fires when logprob confidence < 0.85 or schema validation fails. Uber, GitHub Copilot, Gemini Flash→Pro all production-validated.

Effort: 1 week Risk: Medium All phases
FrugalGPT RouteLLM Hybrid LLM Uber Gateway
See detailed mapping
APPROACH 3 · ALMOST FREE
Aggressive Prompt Caching + Batch API + Constrained JSON
85% input

Anthropic prompt-cache: 10% of base on reads, 90% cost / 85% latency cut. OpenAI Batch API = 50% off for 24h SLA. XGrammar/SGLang/Outlines kill JSON-retry waste. Plus: flip the existing fault_pruning + cache_enabled flags.

Effort: 1–2 days Risk: Very low Phase 0 + 1 + 2
Anthropic Caching OpenAI Batch XGrammar SGLang
See detailed mapping
APPROACH 4
Merge Quant+Qual + Chain-of-Draft + ChainPoll Early-Stop
40% calls · 90% out

Phase 1 currently sends the same 6 spans twice. Merge into one prompt. Chain-of-Draft drops reasoning to 7.6% of CoT tokens at parity accuracy. Galileo ChainPoll: stop sampling once 3-of-5 judges agree.

Effort: 1 week Risk: Medium Phase 1 + Phase 2
Chain of Draft Skeleton-of-Thought ChainPoll Batch Prompting
See detailed mapping
APPROACH 5 · REIMPLEMENTATION
Distilled Small-Model Extractor + NLI Verifier
90%+ steady

Each shipped Phase-1 output is labelled training data. Fine-tune Phi-3-mini / Mistral-7B for bucketing; replace LLM-Council judges with Vectara HHEM-2.1-Open NLI. AWS Bedrock Distillation: 75% cheaper / 500% faster / <2% accuracy delta.
